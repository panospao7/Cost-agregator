## Draft lines

### AI settings and notifications
- **Transaction insight now runs on your device only.** The one-sentence insight shown after you add a transaction is generated by on-device AI and is never sent to a cloud provider. A new "Transaction insight (on-device)" switch in AI settings turns it on or off. New installs have it on; existing installs start with the same value as their Dashboard briefing switch. The insight is generated only while the app is open.
- **Daily briefing and warranty expiry work when notifications are off.** The daily briefing is now generated, and expired warranties are now marked expired, even if notifications are turned off for the app. Notifications are posted only when notifications are allowed; nothing is posted otherwise.
- **"Proactive AI briefings" is now "Notify me when my daily briefing is ready".** It controls only the notification; your briefing still appears on Home when it is off. If notifications are blocked in system settings, AI settings now says so.
- **Background briefing generation (disclosure).** While Enable AI, Dashboard briefing and Allow cloud AI are all on, the daily briefing is generated in the background using cloud AI every midnight, whether or not the notification toggle is on. Before, it was generated only when you opened the dashboard if that toggle was off. All existing consent and privacy settings still apply.

### Warranties
- AI-found warranty periods are no longer saved automatically: suggestions wait for you to confirm them, and the unused cloud warranty extraction is off by default (warranty periods are read on your device). Unconfirmed warranties now expire after their end date and show as "expired without confirmation".

### Assistant (Part C; text from plan section 8)
- "Assistant: 'last week', 'last month', 'last quarter' and 'last year' now mean the previous calendar period (previously the current one was used, e.g. 'food last month' showed this month). Comparisons now use the previous calendar week/month/quarter/year instead of a same-length window. Choosing an option in a clarification keeps your original filters. Smallest-purchase questions are now answered."
- Assistant errors now show a short localized message instead of technical text, and the assistant no longer sends its own earlier replies to the cloud interpreter (only your recent questions, redacted as your privacy settings require).

## Notes for the release owner

- User-visible behaviour changes to confirm: INV-25 background cloud briefing for proactive-off users; "last <period>" semantics (R20/PC-5); unconfirmed warranties now expire.
