## 5. Universal candidates

1. **CancellationException swallowed in a broad catch** (universal category): NEW-P12-2026-002 in ExportOptionsViewModel.generateExport. The U-PR1 fix class covers worker/diagnostic layers but did NOT reach this UI-layer catch. Same family was verified CLEAN in the Pipeline 11 ingestion service.
2. **Raw `e.message` exposure** (universal category "arbitrary e.message persisted/logged/exposed"): NEW-P12-2026-001 in AccountingExportRepository. The PII burn-down (e7f3496e, 92a6ebf7, b2025407, ca760783, f652218f) missed it because the class is production-dead — suggests the burn-down sweeps operated on live call graphs; dead code retains raw-message patterns.
3. **Silent currency assumption** (universal category "mixed-currency money math / silent EUR fallback"): P12-P1-03's missing conversionStatus is the export-side face of it; the parser-side face is NEW-P11-2026-003 (Uber defaults EUR, Apple/Amazon default USD). Both let an unverified currency flow into user-visible data with no quality flag. U-PR money fixes (MoneyAggregate/quality metadata) do not currently extend to export DTOs or parser output.
4. **Snapshot/TOCTOU gap on long-running reads** (universal category "TOCTOU read-outside-transaction"): P12-P1-02 + P12-P1-04 — a long streaming export reads many separate barrier-checked queries with no atomic snapshot; validation and header counts are separate queries. DatabaseReadBarrier fences restore windows but cannot provide read atomicity. Same pattern class as other multi-query read paths in the app.
