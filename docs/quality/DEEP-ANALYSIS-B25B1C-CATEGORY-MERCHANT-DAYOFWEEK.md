| **CategoryInsightEngineTest.kt:16** | 🟡 Medium | Test Isolation / State Leakage | `CategoryInsightEngine` is `@Singleton` in production and has mutable state (`missingCategoryHitCount`). The real semantic bug: `previousMonth` has `month = 1` and `startMs = startOfMonth(2026, 2)`. **No functional bug currently, but the naming discrepancy is a maintenance hazard.** | Add a helper like `fun createMonthPeriod(year: Int, month1Indexed: Int)` that derives `month`, `startMs`, `endMs` consistently. |

### Summary

- **1 High** semantic maintenance hazard (MonthPeriod 0-indexed `month` vs 1-indexed `startOfMonth`)
- **7 Medium** issues (incomplete assertions, missing edge cases, test isolation concerns)
- **3 Low** issues (implicit coverage, documentation, defensive assertions)

### Root Cause Analysis

The dominant pattern is **missing negative/boundary test coverage**. The happy-path golden tests are well-constructed and numerically precise, but they rely on implicit verification. The `MonthPeriod` 0-indexed month convention is the highest-risk item — it's a latent off-by-one bug waiting to happen.
