### Summary

**Critical Issues (🔴 High):**
1. **InsightsEngineValidationTest mock stubs never match** — 7 tests use specific timestamp matchers that don't align with production-computed boundaries. All assertions pass vacuously against default zero values.
2. **InsightsEngineDeepTest `returnsMany` is order-dependent** — fragile coupling to internal async launch order.
3. **AdvancedAnalyticsEngineDeepTest broad `any()` mock overrides specific mock** — potentially corrupts comparison period data.
4. **Production bug**: `MerchantInsight.merchant` uses `merchantKey` instead of `displayName`, validated by a test that asserts the wrong value.

**Medium Issues (🟡):**
- Time-dependent flakiness in InsightsEngineTest (2 locations)
- `Dispatchers.Unconfined` instead of test dispatchers
- Non-relaxed mocks without comprehensive stubs
- DST-sensitive timestamp arithmetic in assertions
- Degenerate `PeriodRange(0, 0)` not testing real behavior
- Tight floating-point tolerances on computed scores
- Missing edge case coverage across all files
