    DAOs wrapped by Repositories with business logic
    Repositories expose Flow<T> for reactive updates

  ✓ COMPOSITE PATTERN (CompositeGeocodingService)
    4 geocoding providers aggregated & merged
    Parallel execution with smart gating
    Re-ranking by qualifier match, deduplication

  ✓ MULTI-IMPLEMENTATION PATTERN (AI Services)
    Cloud / On-Device / Hybrid / NoOp variants
    Dependency injection + settings-based selection
    Enables offline + online + testing scenarios

  ✓ TRANSACTION PATTERN (@Transaction in DAOs)
    Automatic FK resolution
    POJO result mapping (ExpenseWithCategory)
    Extensively used in analytics queries

  ✓ DYNAMIC QUERY PATTERN (@RawQuery)
    Supports dynamic WHERE, ORDER BY, LIMIT
    Used by ExpenseRepository.getExpensesDynamic()
    Enables complex filtering UI

  ✓ ATOMIC OPERATIONS
    dedupeKey UNIQUE index (v21) prevents duplicates
    insertAtomic() with IGNORE conflict strategy
    Checked via SELECT changes()

  ✓ REACTIVE STREAMS
    Flow<List<T>> for subscription-based updates
    Pagination via getPage(limit, offset)
    Prevents OOM on large datasets
