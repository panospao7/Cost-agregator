1	AssistantSheet.kt:58-64	🔴 Critical	Navigation Event Loss	navigationEvents is a Channel.BUFFERED consumed via receiveAsFlow(). The LaunchedEffect(Unit) collector starts when the sheet opens, but if the ViewModel outlives the composable (e.g., configuration change), events emitted while the collector is inactive are silently dropped. Worse, if two composable instances ever share the same VM, only one will receive events.	Use SharedFlow(replay=0, extraBufferCapacity=1, onBufferOverflow=DROP_OLDEST) or ensure a single collector with Lifecycle.repeatOnLifecycle. Alternatively, wrap Channel(Channel.UNLIMITED) to avoid back-pressure drops.
2	AssistantSheet.kt:74	🟡 Medium	Recomposition / State Bug	rememberModalBottomSheetState(skipPartiallyExpanded = true) is called inline inside ModalBottomSheet. Hoist the sheetState to the same scope as listState, e.g. val sheetState = rememberModalBottomSheetState(skipPartiallyExpanded = true) before ModalBottomSheet(sheetState = sheetState, …).
