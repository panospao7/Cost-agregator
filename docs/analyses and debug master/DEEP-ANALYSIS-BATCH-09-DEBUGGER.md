### Summary
- **Total issues: 25** (20 per-file + 5 cross-component)
- **Files with issues: 12/14** (all except `HybridDashboardBriefingService.kt` and `HybridDedupeJudgeService.kt` which are clean thin delegators, though they share cross-component issues C2)
- 🔴 Critical: 2 (enum `valueOf` crashes in `OnDeviceDedupeJudgeService`)
- 🟠 High: 4 (PII leakage x2, race condition, NPE risk)
- 🟡 Medium: 9 (greedy JSON extraction x2, wrong config constant, NaN propagation x2, stale model cache, correlationId, missing role, settings race)
- 🟢 Low: 5 (hardcoded currency, fragile constructor, hardcoded model, locale, string "null")
- Cross-component: 5 (parser inconsistency, settings race, request reuse, dual orchestrator, no model invalidation)

**Top 3 Priorities:**
1. **PII Leakage (#3, #4, Pipeline #5)**: `CloudReviewExplanationService` and `CloudCategorizationAssistService` send raw notification text, merchant names, and package names to Google's cloud API without any sanitization. This is a privacy/compliance risk.
2. **NaN Propagation (#11, #15, #16)**: All on-device services use `optDouble()` without NaN guards. Malformed AI output silently injects `NaN` into financial calculations, filter comparisons, and confidence scores.
3. **Improper Cloud↔OnDevice Coupling (#9, #C2, #C4)**: Cloud services instantiate on-device service classes directly to reuse prompt logic, potentially loading the on-device ML model unnecessarily and creating duplicate cached model instances outside the DI singleton scope.
