### Key Risk Assessment

1. **Highest risk**: Issue #1 (default divergence) — this affects production behavior on fresh installs and could cause receipt assist to appear broken out-of-box despite the data class saying it should be enabled by default.

2. **Most impactful design issue**: Issue #4 (AiMode vs AiRoute in entity) — under the default AUTO mode, **all** diagnostic display text is lost for persisted artifacts, affecting three ViewModels.

3. **User-facing degradation**: Issue #2 (on-device-only capabilities under Cloud preferred) — users who select Cloud mode lose NOTIFICATION_PARSE, REVIEW_PRIORITIZATION, and SEMANTIC_DEDUPE with no feedback about why.
