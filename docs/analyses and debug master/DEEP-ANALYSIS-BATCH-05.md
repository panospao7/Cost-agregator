## Key Patterns
- **Time-window drift on dashboard flows**: multiple layers compute “current month” independently, and some freeze it at subscription time.
- **Dual data paths / inconsistent snapshots**: some widgets use pre-aggregated dashboard data while others re-query repositories directly during assembly.
- **Placeholder or lossy domain mappings**: goal protection levels, category names, and prompt exposure state are either hardcoded or dropped.
- **Forecasting paths are not sharing one obligation model**: dashboard, radar, and savings sweep use different assumptions about upcoming bills and discretionary headroom.
- **Tests exist for several use cases, but they miss the highest-risk regressions**: month rollover, prompt cooldown persistence, future-dated Money Radar spend, strict-goal reserve handling, over-allocation, and misleading zero-overrun messaging are not covered.
