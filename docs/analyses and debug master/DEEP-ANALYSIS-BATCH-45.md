## Key Patterns
- Several engines return placeholder/proxy values as if they were authoritative business data (savings streaks, weekly no-spend rewards, tax summaries).
- Batch/background pipelines expose concurrency and retry problems that happy-path unit tests do not cover.
- Receipt matching and warranty extraction both suffer from cross-script / cross-thread assumptions that break in real multilingual, parallel imports.
- Savings and tax logic are fragmented: multiple modules model the same domain concepts differently, so their outputs can disagree even when fed the same user state.
