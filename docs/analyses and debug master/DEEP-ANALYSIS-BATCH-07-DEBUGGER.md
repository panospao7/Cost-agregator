### Critical Fix Priorities

1. **Issue #3 (DedupeJudgeInputBuilder:113)**: Change `candidates.size < 2` → `candidates.isEmpty()`. This is the highest-impact bug — it silently disables AI duplicate detection for single-candidate pairs, which is the most common duplicate scenario.

2. **Issues #4-6 (Pipeline P2 — Inconsistent Redaction)**: Align all three builders to use `aiPolicy.shouldRedact(settings, capability)` without the `canUseCloudFor` gate. The current pattern creates a TOCTOU vulnerability where PII can leak to cloud.

3. **Issue #11 (Pipeline P3 — Multi-filter Drop)**: `singleOrNull()` silently drops multi-value filters, causing wrong query results. This needs repository-level multi-value support.
