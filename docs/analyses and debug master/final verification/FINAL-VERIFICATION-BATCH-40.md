## Key Patterns
- Forecasting logic is split across multiple engines with different assumptions, producing inconsistent risk outputs and confidence labels.
- Shared-expense math still lacks a single source of truth: budget, balance, and UI paths do not all reuse the same split-resolution logic.
- Historical group calculations remain mutable because expenses do not persist immutable participant/share snapshots.
- Several public/domain APIs still leak infrastructure concerns (Room entities, repositories, hardcoded clocks/dispatchers) and weaken invariant enforcement.
