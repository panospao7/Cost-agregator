## Key Patterns
- Period/window logic is duplicated across multiple layers instead of being centralized, and the implementations have already diverged.
- Confidence and risk heuristics repeatedly conflate “low evidence” with “low risk” or “high stability,” which systematically overstates certainty.
- Shared-budget code bypasses the app's canonical spend semantics (`effectiveAmount`, purchase-only filters, consistent period windows), creating cross-path inconsistencies.
- Several APIs are exposed before they are real (`updateForecastAccuracy()`, `getMemberContributions()`), indicating incomplete features leaking into public domain contracts.
