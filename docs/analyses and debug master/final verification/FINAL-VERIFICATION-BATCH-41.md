## Key Patterns
- The legacy financial-health path has drifted far from the rest of the analytics stack: week boundaries, transaction filtering, budget normalization, and score scaling all differ from the newer components.
- `effectiveAmount` standardization is still incomplete, especially in income/cash-flow features, so shared-expense handling remains inconsistent across user-facing metrics.
- Intelligence model persistence is still fragile: one classifier keeps stale vocabulary state, another persists corrections asynchronously and non-durably, and category caches are treated as immutable process state.
- Duplicate detection is split across incompatible policies (24-hour semantic checks vs 5-minute DB dedupe), so different ingestion paths can make conflicting decisions.
- Investment reporting still contains multiple user-visible semantic errors (fees omitted, mislabeled extrema, incorrect day change, broken portfolio history), so portfolio insights are not yet decision-grade.
