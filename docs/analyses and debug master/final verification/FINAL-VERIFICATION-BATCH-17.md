## Key Patterns
- The batch plan is misaligned with the actual reports: `DEEP-ANALYSIS-BATCH-PLAN.md` defines B17 as repository files, while both B17 reports actually analyze UI screens.
- The transactions pipeline is still the most fragile area in this batch: `ALL` uses a detached snapshot model, filter state is split across multiple sources of truth, and several important edit/filter defects were missed by both reports.
- Retry and failure handling is inconsistent across screens/view-models. Home retry, Budget Forecast retry, Advanced Analytics failure rendering, and Budget suggestions error handling all leave broken or partially recoverable states.
- Time semantics are duplicated instead of centralized. That shows up both in the confirmed drill-down clipping bug and in the broader calendar-vs-rolling “Month” inconsistency.
