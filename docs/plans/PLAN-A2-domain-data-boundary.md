# PLAN A.2 — Domain/Data Layer Boundary Violations

## 1. Objective & Blast Radius
- **The Core Issue:** Multiple domain-layer contracts currently import or expose Room entities / data-layer enums (`Expense`, `Category`, `PendingReview`, `TransactionType`, `AiArtifactEntity`, `OwnershipFilter`). One dashboard path also reconstructs partial `Expense` entities from `DashboardExpense`, which drops shared-expense ownership data and can corrupt downstream calculations.
- **Blast Radius:**
  - **Dashboard / analytics / widgets:** `DashboardContractsAdapter.kt`, `SynthesisEngine.kt`, `InsightsEngine.kt`, `SpendingPaceCalculator.kt`, `ComputeDashboardWidgetsUseCase.kt`, `DashboardWidgetUiMapper.kt`, `BudgetBlockPartyCard.kt`, `RetroBudgetBlockPartyCard.kt`, `HomeViewModel.kt`, `HomeScreen.kt`
  - **AI artifact persistence + diagnostics:** `AiArtifactRepositoryImpl.kt`, `GenerateDashboardBriefingUseCase.kt`, `ExplainPendingReviewUseCase.kt`, `SuggestReceiptExtractionUseCase.kt`, `SuggestCategoryFallbackUseCase.kt`, `JudgePendingReviewDuplicateUseCase.kt`, `CategorizeReceiptItemsUseCase.kt`, `GenerateTransactionInsightUseCase.kt`, `DeliverProactiveBriefingNotificationUseCase.kt`, `HomeViewModel.kt`, `ReceiptScanViewModel.kt`, `ReviewViewModel.kt`
  - **AI categorization / query / dedupe / navigation filters:** `ReceiptItemCategorizationInputBuilder.kt`, `CategorizationAssistInputBuilder.kt`, `CloudReceiptItemCategorizationService.kt`, `OnDeviceReceiptItemCategorizationService.kt`, `InterpretFinancialQueryUseCase.kt`, `ExecuteFinancialQueryUseCase.kt`, `MapFinancialQueryToNavigationUseCase.kt`, `TransactionFilterSerializer.kt`, `TransactionFilterUiMapper.kt`, `DashboardFollowThroughEngine.kt`, `NavigationTargetResolver.kt`, `CrossSourceDeduplication.kt`, `DetectSemanticDuplicateUseCase.kt`, `SemanticDuplicateDetector.kt`, `OnDeviceSemanticDuplicateDetector.kt`, `OnDeviceReviewPriorityScorer.kt`, `AssistantViewModel.kt`
  - **Weather / narrative text path:** `FinancialForecast.kt`, `FinancialWeather.kt`, `FinancialWeatherRepository.kt`, `FinancialWeatherCard.kt`, `DashboardBriefingInputBuilder.kt`
- **Assumptions / unknowns:**
  - This epic is **not** a whole-codebase clean-architecture sweep; scope is the selected A.2 files plus direct compile-neighbor adapters/tests needed to keep behavior stable.
  - `DomainExpenseSummary` is probably sufficient for block-party previews; only introduce a new preview DTO if the UI truly needs more than `id`, `amount`, `description`, and `date`.
  - `AiArtifactRepository` is internal to the app module, but if the team treats it as a stable repository API, the DTO migration needs a temporary deprecation / adapter path.
  - `NarrativeGenerator` may need a phased cleanup: at minimum remove `R` imports from domain; if `UiText` propagation reaches `FinancialWeather`/AI prompt builders, keep that migration in one compile-safe pass.

## 2. The Single Source of Truth (The Standard)
- **Canonical rule:** Domain models must **NEVER** import from `com.yourname.expensetracker.data.database.entity` or `com.yourname.expensetracker.data.repository`.
- All cross-boundary payloads must use domain-owned DTOs / enums in `domain/model/` or `domain/dto/`.
- All entity mappers live in the data / adapter / presentation-adjacent layers only.
- Dashboard rule: `DashboardExpense` and `DomainExpenseSummary` are the canonical downstream transaction shapes for dashboard/block-party flows. **Never** reconstruct `Expense` just to reuse analytics or widget code.
- AI artifact rule: domain code reads/writes a domain artifact record/snapshot; only `AiArtifactRepositoryImpl` knows `AiArtifactEntity`.
- Filter / AI-input rule: `DomainTransactionFilter`, `ExpenseQueryFilters`, `CategorizationAssistInput`, `DuplicateCheckCandidate`, and review-priority helpers must use domain enums / snapshots, not Room enums/entities.
- Narrative rule: domain emits `UiText` / message keys and raw values; Android `R` access and final text resolution belong outside domain.
- **Expected new canonical types:**
  - `domain/model/DomainTransactionType.kt`
  - `domain/model/navigation/DomainOwnershipFilter.kt`
  - `domain/dto/AiArtifactRecord.kt`
  - `domain/dto/CategoryRef.kt`
  - `domain/dto/ReceiptItemCategorizationSnapshot.kt`
  - `domain/dto/ReviewPriorityInput.kt`
