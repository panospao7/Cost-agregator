================================================================================
ARCHITECTURE HIGHLIGHTS
================================================================================

CACHE STRATEGY (3 Tiers):
1. AI Artifact Cache (ai_artifacts table)
   └─ TTL: 2 hours, Hit Rate: 80%+
2. In-Memory Dashboard Cache (Flow-based)
   └─ TTL: Until midnight, Hit Rate: 95%+
3. Recommendation DB Cache (recommendations table)
   └─ TTL: 7 days, Hit Rate: 99%+

RECOMMENDATION LIFECYCLE:
Day 1 (Created)    → status = ACTIVE, expiresAt = Day 8
Day 3 (Dismissed)  → status = ARCHIVED, dismissedAt = timestamp
Day 8 (Expired)    → status = EXPIRED (soft-deleted)
Day 15 (Cleanup)   → Permanently deleted (hard-delete)

DATA RELATIONSHIPS:
ai_artifacts (1) ──→ recommendations (N)
├─ 1 briefing artifact
└─ N follow-through recommendations (via sourceArtifactId)

DESIGN PRINCIPLES:
1. AI summarization only (brief text generated by AI)
2. Deterministic routing (nav targets chosen by app logic)
3. Soft-delete pattern (archive before delete)
4. TTL-based expiry (automatic lifecycle)
5. Loose coupling (no hard FK constraints)
6. Multi-user ready (userId isolation)

DATABASE SCHEMA
================================================================================

Table: recommendations (v32+)
├─ id (TEXT PK) ..................... UUID-based identifier
├─ userId (TEXT NOT NULL) .......... Multi-user support
├─ recommendationText (TEXT NOT NULL) AI-generated summary
├─ navigationTarget (TEXT NOT NULL) .. Target screen (deterministic)
├─ filterCriteria (TEXT NOT NULL) ... Serialized TransactionFilter JSON
├─ createdAt (BIGINT NOT NULL) ..... Epoch millis
├─ updatedAt (BIGINT NOT NULL) ..... Epoch millis
├─ dismissedAt (BIGINT NULLABLE) ... User dismiss timestamp
├─ expiresAt (BIGINT NOT NULL) ..... TTL (createdAt + 7 days)
├─ priority (TEXT NOT NULL) ........ Enum: HIGH, MEDIUM, LOW
├─ category (TEXT NOT NULL) ........ Category tag (FOOD, TRANSPORT, etc)
├─ sourceArtifactId (TEXT NOT NULL) . Link to ai_artifacts.id
├─ status (TEXT NOT NULL) .......... Enum: ACTIVE, ARCHIVED, EXPIRED
└─ Indices:
   ├─ (userId, status, expiresAt) ... Fast active lookup
   ├─ (sourceArtifactId) ........... Traceability
   ├─ (createdAt) .................. Chronological queries
   └─ (expiresAt) .................. TTL sweep cleanup

Migration: MIGRATION_31_32 (AppDatabase v32)
├─ Creates recommendations table
