# Fixtures

This directory is a shadow-only adversarial corpus for the GR-13 mediation analysis: 14 call-binding + 12 helper + 18 worker fixture files (17 worker cases, with WP-15 split into WP-15a/WP-15b) plus 8 protocol fixtures, for 52 manifest rows total; all expected values use closed vocabularies only, and the corpus is fixtures-first — a green run against these fixtures is never a substitute for analysis of the real tree.
