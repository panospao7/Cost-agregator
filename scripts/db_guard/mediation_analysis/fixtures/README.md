# Fixtures

This directory is a shadow-only adversarial corpus for the GR-13 mediation analysis: 15 call-binding + 25 helper + 18 worker fixture files (17 worker cases, with WP-15 split into WP-15a/WP-15b) plus 8 protocol fixtures, for 66 manifest rows total (HP-13..HP-20 are the GR-14f inline-carrier rows, SL-01..SL-03 the GR-14j structured-launch rows); all expected values use closed vocabularies only, and the corpus is fixtures-first — a green run against these fixtures is never a substitute for analysis of the real tree.
